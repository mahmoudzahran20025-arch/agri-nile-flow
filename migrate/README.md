# أداة استيراد بيانات Excel إلى D1

هذا الـ CLI يقرأ ملفات Excel الثلاثة لشركة نواة المستقبل ويدرج البيانات مباشرة في D1.

## الملفات المطلوبة

ضع الملفات في نفس مجلد `migrate/`:

| الملف | المحتوى |
|-------|---------|
| `suppliers.xlsx` | الموردين + حركات حسابات الموردين |
| `treasury.xlsx` | دفتر اليومية النقدية |
| `inventory.xlsx` | حركات المخزون |

## التشغيل

```bash
cd migrate

# تثبيت الاعتمادات
npm install

# 1. استيراد الموردين (أولاً — الحركات تعتمد عليهم)
node import.js suppliers

# 2. استيراد الخزينة
node import.js treasury

# 3. استيراد المخزون
node import.js inventory

# أو الكل دفعة واحدة
node import.js all
```

## الإعداد

عدّل `config.js` لتحديد:
- أسماء الـ sheets داخل كل ملف Excel
- رقم الصف الذي تبدأ منه البيانات
- أسماء الأعمدة وتطابقها مع حقول D1
