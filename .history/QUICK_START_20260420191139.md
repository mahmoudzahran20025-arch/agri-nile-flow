## ⚠️ Troubleshooting

### المشكلة: "الصفحات فارغة"
**الحل:**
```
1. تأكد من تسجيل الدخول ✅
2. افتح Developer Tools (F12)
3. شاهد Console لأي أخطاء
4. جرب Ctrl+Shift+R (hard refresh)
```

### المشكلة: "خطأ في التحميل"
**الحل:**
```
1. تحقق من الإنترنت ✅
2. جرب صفحة مختلفة
3. افتح Debug page واختبر APIs
4. راقب Network tab في F12
```

### المشكلة: "لا أستطيع تسجيل الدخول"
**الحل:**
```
1. تأكد من كتابة البريد صحيح: admin@nawa.eg
2. تأكد من كتابة كلمة السر صحيح: Admin@2025
3. اختر الشركة: نواة المستقبل
4. جرب Ctrl+F5 (clear cache + refresh)
```
