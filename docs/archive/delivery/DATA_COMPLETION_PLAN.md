## 🔍 سبب المشكلة

### مشكلة ترميز التواريخ
- ملفات Excel تحتوي على تواريخ بتنسيق **Excel Serial Date**
- السكريبتات الأولية لم تحول التواريخ بشكل صحيح
- البيانات القديمة تظهر كأنها "خارج النطاق" ولم تُستورد

**مثال:**
- Excel serial: `45292`
- التاريخ الحقيقي: `2023-12-31`
- ما تم فهمه: غير صالح

## 📁 ملفات الاستيراد المطلوبة

### 1. استكمال الموردين (`الموردين والعملاء`)

```javascript
// استيراد 19 مورد مفقود
// من شيت "الكود" في ملف الموردين
```

**الأعمدة المطلوبة:**
- كود المورد (code)
- اسم المورد (name)
- النشاط (activity)
- العنوان (address)
- التليفون (phone)

### 2. استكمال الأصناف (`مخازن`)

```javascript
// استيراد 4,778 صنف مفقود
// من شيت "الكود" في ملف المخازن
```

**الأعمدة المطلوبة:**
- كود الصنف (code) — 7 أرقام
- اسم الصنف (name)
- الوحدة (unit)
- الفئة (category) — من كود الصنف

**نمط الأكواد:**
```
1010xxx = أسمدة → FERT
1020xxx = مبيدات → CHEM
1030xxx = تقاوى → SEED
1050xxx = معدات → EQUIP
1070xxx = مستلزمات → SUPPLY
```

### 3. استكمال حركات المخزون

```javascript
// استيراد 9,869 حركة مفقودة
// من شيت "البيانات" في ملف المخازن
```

**الأعمدة المطلوبة:**
- التاريخ (movement_date)
- كود الصنف (item_code)
- كود المخزن (warehouse_code)
- نوع الحركة (movement_type) — اضافة/صرف
- الكمية (quantity)
- السعر (unit_price)
- القيمة (value)
- كود المورد (supplier_code)

### 4. استكمال حركات الموردين

```javascript
// استيراد 15,252 حركة مفقودة
// من شيت "البيان" في ملف الموردين
```

**الأعمدة المطلوبة:**
- التاريخ (transaction_date)
- كود المورد (supplier_code)
- نوع الحركة (transaction_type) — فاتورة/دفعة
- المبلغ (amount)
- رقم المستند (document_number)
- البيان (description)

### 5. استكمال حركات الخزينة

```javascript
// استيراد 19,846 حركة مفقودة
// من شيت "البيان" في ملف الخزينة
```

**الأعمدة المطلوبة:**
- التاريخ (transaction_date)
- البيان (description)
- دائن (debit) — وارد
- مدين (credit) — منصرف
- رقم المستند (document_number)
- المركز (center_code)
