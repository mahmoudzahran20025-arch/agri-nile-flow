**الحالة:** ✅ مستورد بالكامل (349/352)

**الهيكل:**
```
الأصول (1000-1999)
  ├─ النقدية (1401)
  │   ├─ الخزينة (140101)
  │   └─ البنك (140103)
  └─ المخزون (1407)
      ├─ أسمدة (140701)
      ├─ مبيدات (140702)
      └─ تقاوى (140703)

المطلوبات (2000-2999)
  ├─ موردين (2100)
  └─ أجور مستحقة (2120)

الإيرادات (4000-4999)
  ├─ مبيعات (4101)
  └─ إيرادات أخرى (4200)

المصروفات (5000-5999)
  ├─ مشتريات (4501)
  └─ مصروفات تشغيلية (5100)
```

**الحالة:** ⚠️ مستورد جزئياً (10/29)

**الهيكل:**
```
شيت "الكود" (Master Data)
  ├─ كود المورد (مفتاح رئيسي)
  ├─ اسم المورد
  ├─ النشاط (زراعي/تجاري/حكومي)
  └─ البيانات (عنوان، تليفون، رصيد افتتاحي)

شيت "البيان" (الحركات — 15,565)
  ├─ تاريخ الحركة
  ├─ كود المورد (ربط مع Master)
  ├─ نوع الحركة:
  │   ├─ فاتورة (مشتريات)
  │   ├─ سند صرف (دفعة للمورد)
  │   ├─ مرتجع
  │   └─ تحويل
  ├─ المبلغ
  ├─ رقم المستند
  └─ الرصيد الجاري

شيت "النشاط" (التصنيفات)
  └─ تصنيف الموردين حسب النشاط
```

**نقطة الضعف:**

- 15,252 حركة غير مستوردة
- الروابط مع GL مفقودة (journal_entry_id = NULL)

### 3️⃣ ملف: خزينة (النقدية)
**الحالة:** 🔴 مستورد جزئياً جداً (69/19,915)

**الهيكل:**
```
شيت "البيان" (الحركات — 19,915)
  ├─ التاريخ (Excel serial date)
  ├─ البيان (وصف الحركة)
  ├─ عمود "د" (دائن = وارد)
  ├─ عمود "م" (مدين = منصرف)
  ├─ الرصيد (الرصيد الجاري)
  ├─ رقم المستند
  └─ اسم المستلم/المورد

شيت "مساهمة الشركاء"
  └─ مساهمات رأس المال
```

**نمط البيانات:**
```javascript
// حركة واردة (دائن)
{ date: '2025-01-15', debit: 0, credit: 50000, narration: 'بيع محصول' }

// حركة منصرفة (مدين)
{ date: '2025-01-15', debit: 25000, credit: 0, narration: 'شراء أسمدة' }
```

**نقطة الضعف:**
- 99.7% من الحركات غير مستوردة
- مشكلة في ترميز التواريخ
- جميع الحركات المستوردة بدون ربط GL

### 4️⃣ ملف: مخازن (المخزون)
**الحالة:** ⚠️ مستورد جزئياً (700/10,569)

**الهيكل:**
```
شيت "الكود" (الأصناف — 4,839)
  ├─ كود الصنف (7 أرقام)
  │   ├─ 1010xxx = أسمدة
  │   ├─ 1020xxx = مبيدات
  │   ├─ 1030xxx = تقاوى
  │   ├─ 1050xxx = معدات
  │   └─ 1070xxx = مستلزمات
  ├─ اسم الصنف
  ├─ الوحدة (كجم، لتر، قطعة)
  └─ الرصيد الافتتاحي

شيت "البيانات" (الحركات — 10,569)
  ├─ التاريخ
  ├─ المخزن (اسمدة، مبيدات، تقاوي...)
  ├─ كود الصنف (ربط مع Master)
  ├─ المورد (ربط مع ملف الموردين)
  ├─ نوع الحركة:
  │   ├─ "اضافة" = إضافة للمخزون (شراء/استلام)
  │   └─ "صرف" = صرف من المخزون (بيع/استخدام)
  ├─ الكمية
  ├─ السعر
  └─ القيمة = الكمية × السعر

شيت "بطاقة صنف" (تفاصيل — 2,496)
  └─ تفاصيل إضافية لكل صنف

شيت "ارصدة المخازن" (الأرصدة — 971)
  ├─ المخزن
  ├─ الصنف
  └─ الرصيد الحالي

شيت "البيان اليومي" (التقرير اليومي — 364)
  └─ ملخص يومي للحركات

شيت "كشف حساب مورد" (كشوفات — 293)
  └─ كشف حساب لكل مورد

شيت "تكاليف مراكز" (التكاليف — 1,307)
  └─ تكاليف مراكز الإنتاج
```

**نقطة الضعف:**
- 93% من الأصناف غير مستوردة (4,778 مفقود)
- 93% من الحركات غير مستوردة (9,869 مفقود)
- فرق 47 صنف في الأرصدة
- بعض الروابط مع GL مفقودة (104/700)

## 🔗 الروابط الحقيقية والمطلوبة

### الربط 1: المخزون ↔ GL ✅ (جزئي)
```
حركة مخزون (اضافة)
  │
  ├─ يُنشئ قيد في GL:
  │   ├─ DR: المخزون (140701) — حساب أصول
  │   └─ CR: الموردين (2110) — حساب مطلوبات
  │       أو CR: النقدية (140101) — إذا كانت نقدية
  │
  └─ تُحدث journal_entry_id في حركة المخزون
```
**الحالة:** 596/700 مربوطة ✅

### الربط 2: الموردين ↔ GL ❌ (مفقود)
```
حركة مورد (فاتورة)
  │
  ├─ يُنشئ قيد في GL:
  │   ├─ DR: المشتريات (45010001) — حساب مصروفات
  │   └─ CR: الموردين (2110) — حساب مطلوبات
  │
  └─ تُحدث journal_entry_id في حركة المورد
```
**الحالة:** 0/313 مربوطة ❌

### الربط 3: النقدية ↔ GL ❌ (مفقود)
```
حركة خزينة (واردة)
  │
  ├─ يُنشئ قيد في GL:
  │   ├─ DR: النقدية (14010101) — حساب أصول
  │   └─ CR: الإيرادات (41010001) — حساب إيرادات
  │
  └─ تُحدث journal_entry_id في حركة الخزينة
```
**الحالة:** 0/69 مربوطة ❌

**الحل:**
```javascript

}
```
